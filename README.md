# IT Help Desk Ticket System

AI-powered IT Help Desk Ticket System built with Python, Flask, SQLite, and Groq AI for automated issue resolution and ticket management.

## ✨ Features

- IT Ticket Submission Portal
- AI-Powered Troubleshooting using Groq AI
- Ticket Management System
- Admin Dashboard
- Ticket Status Tracking
- SQLite Database Integration
- Responsive Web Interface
- Fast Issue Resolution
- Ticket History Tracking

## 🚀 Technologies Used

- Python
- Flask
- SQLite
- Groq AI
- HTML
- CSS
- JavaScript
